## Table of Contents

### 1. Introduction
Technical recruiters are increasingly unable to distinguish between candidates who possess genuine programming ability and those who rely on AI tools such as ChatGPT and GitHub Copilot during technical assessments.
AEGIS is an adversarial assessment platform designed to close this gap. The system allows recruiters to build technical assessments using questions that have been deliberately engineered to mislead AI models while remaining solvable by candidates with genuine understanding.
